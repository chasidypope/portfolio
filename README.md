# Chasidy Pope | IT Portfolio

Professional ivory-and-dusty-pink portfolio, built using HTML, CSS, and vanilla JavaScript. Based on the approved full-site sketch and uses Chasidy's original uploaded photos and illustrations.

## Preview

Double-click `index.html`, or use VS Code's Live Server extension. The navigation links, hardware image viewer, external project links, and résumé download link work without any build tools.

## Publish to GitHub Pages

1. Open your existing public `portfolio` repository at `github.com/chasidypope/portfolio`.
2. Upload the **contents** of this folder to the repository root, replacing the older site files. Upload the entire `assets` folder too.
3. Go to Settings → Pages and use Deploy from a branch → `main` → `/(root)`.
4. Your website will be at `https://chasidypope.github.io/portfolio/`.
5. Refresh your browser after deployment (Ctrl+Shift+R) if the old design remains cached.

## Editing content

- Edit the page copy and links in `index.html`.
- Edit colors and layout in `style.css`.
- `script.js` controls the mobile navigation and photo lightbox.
- Your original photos and illustrations are in `assets/`; the résumé PDF is `assets/Chasidy-Pope-Resume.pdf`.

This site doesn't require Supabase or any credentials: Study Buddy is a linked, separate project.

**Publishing note:** Make sure you have permission to publicly reuse any third-party illustrations in the assets folder.
