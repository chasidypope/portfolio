# Chasidy Pope — Personal IT Portfolio 🌸

A responsive portfolio built with plain HTML, CSS, and JavaScript, featuring the **actual photos and illustrations uploaded for this website** (not AI-generated replacements).

## Preview locally

Open `index.html` in your browser, or use the VS Code **Live Server** extension.

## Publish on GitHub Pages

1. Make a public repository, such as `portfolio`.
2. Upload **the contents of this folder** (`index.html`, `style.css`, `script.js`, `assets/`, and this README). Do not upload just the ZIP.
3. In the repository go to **Settings > Pages > Build and deployment**.
4. Select **Deploy from a branch** and choose `main`, `/(root)`, and **Save**.
5. Visit the URL GitHub provides. The `index.html` file must be in the root directory.

## Functionality

- Responsive desktop/mobile layout and mobile navigation
- Links to the live Study Buddy app, its source code, LinkedIn, and GitHub
- Light/dark theme toggle (saved to browser)
- Interactive galleries for PC and keyboard photos (click photos, use arrow keys or buttons to switch, Escape to close)
- Expandable hardware build details
- Résumé PDF preview and download
- Accessible navigation and keyboard support

## Personalization

- Your PDF is `assets/Chasidy_Pope_Resume.pdf`. Replace this file with a newer résumé at any time while keeping its name.
- To change copy or links, edit `index.html`.
- All visual assets are in `assets/`. The keyboard close-up is **cropped from your actual uploaded desk photo**, not generated.
- Ensure you have permission to publish any third-party illustrated artwork on your public site. The photo assets are included exactly as supplied or, for the keyboard, cropped from the original.
- No contact form collects personal data. The Contact section links to LinkedIn, GitHub, and the résumé.
